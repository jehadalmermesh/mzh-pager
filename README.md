# بيجر مزهرية

بيجر إلكتروني مستقل تماماً عن نظام «جرس»: مستودع مختلف، واستضافة مختلفة، وبدون أي بيانات مشتركة.

| الرابط | الشاشة |
|---|---|
| `/` | شاشة الكاشير (الآيباد): تكتب رقم الطلب، وتضغط «جاهز» ثم «تم الاستلام» |
| `/display` | شاشة الكود المقابلة للعميل: يطلع فيها QR كل طلب جديد |
| `/stats` | التحليلات: الطلبات، وقت التحضير، وصول التنبيه، وقت الاستلام، التقييمات، تحويلات قوقل ماب |
| `/?o=رقم&t=كود` | صفحة العميل: رقم نقطي، رنين عند الجاهزية، زر «جاي»، ثم التقييم |

## الإعدادات
عدّل `settings.json` (روابط المنيو، الخريطة، رابط التقييم في قوقل ماب، الموقع، الحسابات).
الروابط لازم تبدأ بـ `https://`، والفاضي ما يظهر. وتقدر بدلها تستخدم متغيرات بيئة: `LINK_MENU`, `LINK_MAPS`, `LINK_REVIEW`, `LINK_WEBSITE`, `LINK_INSTAGRAM`, `LINK_TIKTOK`, `LINK_X`, `LINK_SNAPCHAT`.

## البيانات
سجل الطلبات (للتحليلات) ينحفظ في `data/orders.json` لمدة 90 يوم. غيّر المكان بـ `DATA_DIR` (مثلاً قرص دائم على Render).

التشغيل: `npm start` — بدون أي مكتبات إضافية.
